# Namche Thakali Kitchen & Inn

One-page restaurant website (Vite + React + TypeScript).

## Run locally

```bash
cd web
npm install
npm run dev
```

## Edit restaurant details

Update everything in one place:

- `web/src/data/restaurant.ts` — address, phone, WhatsApp, hours, menu, social links
- Drop a real Reel/video at `web/public/videos/reel.mp4` and set `reelVideoSrc` in that same file

## Build for production

```bash
cd web
npm run build
npm run preview
```
